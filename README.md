# Vowloom Studio II

双语婚礼纸品工作台：宾客名单、可视化排座与整套纸品联动。界面为英文，支持中文及法语重音字符。

## 本地运行

安装 Node.js 22.13 或更新的受支持版本，然后在仓库根目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的网址（通常为 http://localhost:3000）。首页展示模板，`/studio` 是编辑工作台。

检查和构建：

```sh
npx tsc --noEmit
npm run build
```

## 已有功能

- 三套原创纸品样式：Modern Minimal、Garden、Classic Romance。
- CSV / 粘贴宾客导入；双语姓名、桌号、个人感谢语。
- 圆桌可视化、移动桌子、宾客分桌、缩放和平移；排座页当前会话支持最近 30 次撤销。
- 支持键盘操作的桌子选择菜单，以及原有列表分桌方式。
- 三种墨色、两种字体；姓名、桌号和文案同步到四类纸品。
- 空姓名、未分桌、超容量和可能重复的宾客提示。
- 本机自动保存，JSON 备份和恢复；兼容第一版备份。

## 数据与打印

宾客数据只保存在当前浏览器、当前网址和设备上，不会上传至服务器。更换设备、浏览器或网址前请下载 JSON 备份。最多 500 位宾客、100 张桌子；示例婚礼为虚构数据。

打印尺寸：座位海报 18×24 英寸；故事桌卡 5×7 英寸；姓名卡 3.5×2 英寸（每张 Letter 纸 8 张）；感谢卡 5×3.5 英寸。

使用 Print / Save as PDF；若内嵌浏览器未显示打印窗口，下载纸品 HTML 文件，在 Chrome / Edge 中打开后打印。设置 100% 比例、无边距、关闭页眉页脚并启用背景图形。文字溢出时会提示调整后再导出。没有印刷出血、裁切标记或专业色彩管理。

## 开源依赖

React Konva 19.2.6 和 Konva 10.3.3（MIT）用于排座交互；PapaParse 用于 CSV，Base UI / shadcn 用于界面组件。Seating-Planner 仅作调研参考，没有复制其源代码。具体依赖及许可证请查看 package.json 和各依赖包。

## 验证与范围
